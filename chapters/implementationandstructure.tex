\subsubsection{Development Environment}
The implementation of the experiments was developed in Python 3.11, utilizing the PyTorch library for deep learning model construction and training. The experiments were conducted in a Jupyter Notebook environment, and the GPU(General Purpose Unit) acceleration was leveraged using Apple M4 hardware. The following libraries were used throughout the implementation:
\begin{itemize}
    \item \textbf{PyTorch 2.10}: For building and training the convolutional neural network models.
    \item \textbf{Torchvision 0.25}: For loading and preprocessing the CIFAR-10 dataset.
    \item \textbf{pytorch-grad-cam} — GradCAM implementation 
    for explainability analysis
    \item \textbf{Captum 0.8} — model interpretability 
    library for Integrated Gradients.
    \item \textbf{NumPy 1.26} — numerical computation 
    and array manipulation
    \item \textbf{Matplotlib 3.10} — visualization of 
    training metrics and saliency maps
    \item \textbf{Scikit-learn 1.8} — evaluation metrics 
    and statistical analysis
    \item \textbf{ipykernel 7.2.0} — interactive development and

\end{itemize}
